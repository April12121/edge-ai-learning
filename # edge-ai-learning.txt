# Edge AI Learning — 端侧 LLM 部署实战

基于 llama.cpp 的端侧大语言模型部署与量化方案对比实验。

## 项目背景

验证端侧（Edge）部署量化 LLM 的可行性，建立量化选型基线，为 NXP i.MX 系列等边缘 SoC 的端侧 LLM 部署提供数据参考。

## 测试环境

| 项目 | 配置 |
|---|---|
| 操作系统 | Windows 10 |
| 构建环境 | MSYS2 UCRT64 |
| 编译器 | GCC 16.2.0 |
| 构建工具 | CMake 4.4.2 + Ninja 1.13.2 |
| 推理引擎 | llama.cpp（源码编译，540 个编译目标） |
| 推理硬件 | 12th Gen Intel(R) Core(TM) i7-12700H (2.30 GHz)（纯 CPU 推理） |

## 模型信息

- 模型：Qwen2-0.5B-Instruct（GGUF 格式）
- 量化版本：Q4_K_M / Q8_0

## 测试结果

| 指标 | Q4_K_M | Q8_0 |
|---|---|---|
| 模型体积 | 401 MB | 约 600 MB |
| Prompt 处理速度 | 159.1 tokens/s | 156.7 tokens/s |
| 文本生成速度 | 42.2 tokens/s | 40.3 tokens/s |
| 中文输出质量 | 语义通顺 | 语义通顺 |

## 关键结论

1. **Q4_K_M 生成速度略优于 Q8_0**（42.2 vs 40.3 t/s）——权重体积减半降低了内存带宽压力
2. **端侧 LLM 推理瓶颈在内存带宽，而非算力精度**
3. Q4 在体积缩减约 33% 的前提下质量损失可接受，是端侧部署的性价比之选
